## 🎯 How to Use New Features

### 1. Start All Services
```bash
# Terminal 1: Frontend
npm run dev

# Terminal 2: Backend
cd backend && npm run dev

# Terminal 3: AI Agent
cd ai-agent && python server.py
```

### 2. Access Features
- **Command Palette**: Press `Cmd+K` (Mac) or `Ctrl+K` (Windows/Linux)
- **AI Dashboard**: Navigate to `/ai-dashboard`
- **AI Chat**: Available in dashboard or as standalone component
- **Premium Components**: Import from `@/components/advanced/`

### 3. Enable Advanced Features
```env
# ai-agent/.env
RAG_ENABLED=true
CODE_INTELLIGENCE_ENABLED=true
SELF_HEALING_ENABLED=true
```
