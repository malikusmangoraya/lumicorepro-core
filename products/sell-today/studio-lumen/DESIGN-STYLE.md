# Design Style — Animaster Motion UI

- **Project:** `studio-lumen`
- **Style id:** `animaster`
- **DNA:** Kinetic typography, text morphing, magnetic buttons, glowing border beams, fluid micro-interactions.
- **Typography:** Outfit / Inter
- **Tokens:** `frontend/design-tokens.json`, applied via CSS custom properties in `frontend/src/index.css`
- **Original assets:** `frontend/public/assets/animaster/` (hero, icons, backgrounds, illustrations, mockups) — 100% self-generated vector art. See `frontend/public/assets/manifest.json`.
