## Option A — Run with Docker (recommended, no technical skills required)

1. Install Docker Desktop (https://www.docker.com/products/docker-desktop)
2. Open a terminal in this folder and run:

   ```bash
   docker compose up -d
   ```

3. Open http://localhost:8080
4. The Setup Wizard takes you through admin account + business details.
5. Optionally seed realistic demo content:

   ```bash
   docker compose exec backend node backend/scripts/production-seed.js
   ```

## Option B — Run with Node.js

1. Install Node.js 20+ (https://nodejs.org) and PostgreSQL 15+.
2. Create a database, then copy `.env.example` to `.env` and fill in:

   ```env
   DATABASE_URL=postgres://USER:PASS@localhost:5432/YOURDB
   # Generate: node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
   # Minimum 32 chars. The backend refuses to start if missing, short, or a placeholder.
   JWT_SECRET=
   ```

3. Install and start:

   ```bash
   npm install
   npm run setup        # creates tables + seeds demo data
   npm run dev:full     # frontend + backend
   ```

4. Open http://localhost:5173 and finish setup in the browser wizard.

## Configuring payments / email without code

1. Log in as **admin**.
2. Open the **Admin Dashboard → Global System Settings**.
3. Paste your Stripe / PayPal / SMTP keys and press **Save**.
   - Until keys are added, checkout returns a friendly
     _"Payment system unconfigured"_ message — nothing breaks.

---

## Going live

1. Deploy the folder to any host (Vercel, Railway, Render, VPS, Netlify).
2. Set the environment variables listed in `.env.example` (or use the
   Admin Settings panel for keys).
3. Point your domain, enable HTTPS, done.
