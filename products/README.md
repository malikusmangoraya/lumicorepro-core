## What every product contains

```
<product>/
├── frontend/          React 19 + Vite, 14 languages, RTL for Arabic & Urdu
├── backend/           Node 22 + Express API, PostgreSQL, Redis
├── database/          Schema and migrations
├── docker-compose.yml App + database + cache, with health checks
├── .github/workflows/ CI (build + boot probe) and Pages deploy
└── *.md               README, DEPLOYMENT, SECURITY, CHANGELOG, BUYER_DOCUMENTATION,
                       COMMERCIAL_LICENSE, LEMON_SQUEEZY_SELLER_KIT, BRAND_GUIDELINES
```

Every product ships the same baseline:

* **Identity** — a generated logo mark used everywhere: favicon, PWA icons,
  Apple touch icon, social share image and the React navbar/footer lockup.
  See each product's `BRAND_GUIDELINES.md`.
* **Authentication** — register, sign in, sign out, password reset, email
  verification, rotating refresh tokens and optional TOTP two-factor.
* **Internationalisation** — 14 locales with right-to-left layouts and
  locale-aware dates, numbers and currency.
* **Docker** — multi-stage images and a Compose file with health checks.
* **CI/CD** — a pipeline that fails loudly: it installs, builds, parses every
  backend module and boots the API.
* **Live demo** — a GitHub Pages workflow that publishes the built frontend.
