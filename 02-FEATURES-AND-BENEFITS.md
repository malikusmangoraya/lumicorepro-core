## 3. Cross-product features (core mein, sab ko milein)

**Standard:** Auth, RBAC, profile, notifications, search, dark mode, responsive, PWA

**Pro:**
- Organizations/teams + invites
- Webhooks (outgoing) + API keys
- CSV/Excel import/export
- Email templates (editable)
- Activity feed
- Saved filters, bulk actions

**Premium:**
- White-label (logo, colors, domain, email sender)
- SSO (SAML/OIDC)
- Advanced audit + data retention policy
- Backup/restore tooling
- Command palette, keyboard shortcuts
- Usage metering + plan limits

## 4. Buyer ko kya faida (marketing language)

Har feature ko is format mein likho:
> **Feature** -> **Kya karta hai** -> **Buyer ka asal faida (waqt/paisa/risk)**

Misaal:
> *Claim tracking link -> Customer bina call kiye status dekhta hai -> Support tickets 40% kam* (apna asal number test karke likho, jhoota number mat likho).

## 5. Differentiation checklist (har product ke liye)

- [ ] Home page par pehli 5 second mein samajh aaye ye kis ke liye hai
- [ ] Kam az kam 5 aise features jo 10 doosre products mein nahi
- [ ] Niche ki apni terminology (e.g. "Adjuster", "NAV", "Run sheet")
- [ ] Niche ka sample data realistic ho (lorem ipsum nahi)
- [ ] Alag UI personality (typography, colors, imagery), sirf rang badalna kaafi nahi
- [ ] Faltu models/routes hata diye gaye hon
