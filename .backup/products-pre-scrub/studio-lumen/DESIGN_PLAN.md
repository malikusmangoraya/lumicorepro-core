# Design Plan

This project ships an internationally planned design system — the style,
color language, and target market were decided before a single page was built.

- **Project**: studio-lumen
- **Brand**: Studio
- **UI style**: minimalist
- **Target market**: south-asia — South-Asian energy: saffron + green, warm canvas
- **Design Vault source**: built-in wheel
- **Display font**: Poppins
- **Body font**: Roboto
