# Design Style — Minimalism

- **Project:** `saffron-voyage`
- **Style id:** `minimalism`
- **DNA:** White space, simple typography, 1-2 accent colors, content-first.
- **Typography:** Inter / Inter
- **Tokens:** `frontend/design-tokens.json`, applied via CSS custom properties in `frontend/src/index.css`
- **Original assets:** `frontend/public/assets/minimalism/` (hero, icons, backgrounds, illustrations, mockups) — 100% self-generated vector art. See `frontend/public/assets/manifest.json`.
